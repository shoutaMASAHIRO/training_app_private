# Fitness App

リアルタイムでワークアウトスケジュールを管理し、ユーザー認証を提供するクロスプラットフォームのフィットネスアプリケーションです。

## プロジェクト概要

このプロジェクトは、ユーザーが日々のワークアウトを追跡、スケジュールし、管理できるように設計されたモバイルアプリケーションです。ユーザー認証機能を備え、予定されたワークアウトをカレンダー形式で表示したり、事前に定義されたトレーニングメニューを選択して詳細を確認したりできます。

## アーキテクチャ概要

このプロジェクトは主にクライアントアプリケーションで構成されています。

### フロントエンド (/)
Flutterで構築されたクロスプラットフォームアプリケーションです。バックエンドAPI（想定）と通信し、チャート表示やユーザー操作などのUI/UXを提供します。

### バックエンドAPI (想定)
現在、このアプリケーションはクライアントサイドのみの実装ですが、データ永続化、ユーザー認証、スケジュール管理などの機能のために、互換性のあるバックエンドAPIとの連携を想定しています。

## 主な機能

*   **ユーザー認証**: ログイン、サインアップ機能。
*   **ダッシュボード**: スケジュールされたワークアウトをカレンダーで表示し、当日のワークアウト概要を提供します。
*   **ワークアウトスケジュール管理**: ワークアウトの追加、完了、削除。
*   **ワークアウトメニュー選択**: 定義されたトレーニングメニュー（例: "Smolov Jr."、"10x10"）から選択し、詳細画面へ遷移できます。
*   **プロフィール**: ユーザープロファイルの管理（未実装）。

## 技術スタック

### フロントエンド (Flutter)
*   **Flutter / Dart**: Googleが開発したUIツールキットおよびプログラミング言語。単一のコードベースからiOS、Android、Webなどのクロスプラットフォームアプリケーションを構築するために使用されます。
*   **provider**: Flutterの状態管理パッケージ。シンプルかつ効率的な方法でウィジェットツリー全体に状態を公開・共有するために使用されます。
*   **http**: DartのHTTPパッケージ。REST APIとの通信（データの送受信）を容易に行うための機能を提供します。
*   **intl**: 国際化（Internationalization）と地域化（Localization）をサポートするDartパッケージ。日付、時刻、数値、通貨などのフォーマットや解析に使用されます。
*   **collection**: Dartのコレクション型（リスト、マップ、セットなど）を操作するためのユーティリティ関数やアルゴリズムを提供するパッケージです。`firstWhereOrNull`のような便利な拡張機能が含まれます。
*   **table_calendar**: カスタマイズ可能なカレンダーウィジェットを提供するパッケージ。ダッシュボード画面でワークアウトスケジュールを表示するために使用されます。
*   **shared_preferences**: シンプルなキーバリューペアデータを永続的に保存するためのFlutterプラグイン。ユーザー設定や認証トークンなど、軽量なデータをローカルに保存するために利用されます（将来的に利用される可能性）。

### バックエンド (想定)
*   **Node.js / Express.js**: データ永続化や認証、スケジュール管理などのAPI機能を提供するために、互換性のあるAPIサーバーが必要となります。
*   **PostgreSQL**: (想定される) バックエンドAPIのデータベースとして利用。リレーショナルデータベースであり、データの構造化と信頼性の高い管理に適しています。

## セットアップと起動

### 前提条件
*   **Flutter SDK**: お使いのシステムにインストールされている必要があります。

### 1. バックエンドAPIの起動 (開発時のみ)
このアプリケーションはバックエンドAPIと通信することを想定しています。開発中は、互換性のあるAPIサーバー（例: `http://localhost:3000` またはAndroidエミュレータからアクセス可能な `http://10.0.2.2:3000`）が別途稼働している必要があります。

### 2. フロントエンドアプリの起動

1.  **ディレクトリの移動**:
    ```bash
    cd C:\src\training\fitness_app
    ```
2.  **依存関係のインストール**:
    ```bash
    flutter pub get
    ```
3.  **クリーンアップと再ビルド (推奨)**:
    ```bash
    flutter clean
    ```
    ```bash
    flutter pub get
    ```
    *(以前のビルドキャッシュの問題を避けるため、クリーンと再取得を推奨します)*
4.  **アプリケーションの実行**: （接続したいデバイスを選択した上で）以下のコマンドを実行します。
    ```bash
    flutter run
    ```

## アーキテクチャのポイント

*   **クロスプラットフォーム**: Flutterを使用しているため、単一のコードベースからiOS、Android、Webアプリケーションを構築できます。

# フィットネスアプリ

このアプリケーションは、FlutterフロントエンドとNode.jsバックエンドで構成され、Dockerによって連携して動作するシンプルなフィットネス追跡アプリです。

## 前提条件

開始する前に、以下のソフトウェアがシステムにインストールされていることを確認してください。

-   **Flutter SDK:** フロントエンドアプリケーションの依存関係を管理するためにFlutterが必要です。インストールされていない場合は、公式のインストールガイドに従ってください。
    -   [Flutter - Get Started](https://docs.flutter.dev/get-started/install)

-   **Docker Desktop:** アプリケーションスタック全体（フロントエンド、バックエンド、データベース）をコンテナで実行するために必須です。システムにインストールされ、起動していることを確認してください。
    -   [Docker Desktop](https://www.docker.com/products/docker-desktop/)

## セットアップと起動手順

アプリケーションを起動するには、以下の手順に従ってください。

### 1. Flutterの依存関係をインストール

まず、`fitness_app` ディレクトリに移動し、必要なパッケージをFlutterにインストールさせます。

```bash
cd fitness_app
flutter pub get
cd ..
```
*このコマンドは `pubspec.yaml` ファイルを読み込み、フロントエンドに必要なライブラリをダウンロードします。*

### 2. Dockerでビルドして実行

Docker Desktopが起動していることを確認し、プロジェクトのルートディレクトリから以下のコマンドを実行します。この単一のコマンドで、ソースコードからDockerイメージがビルドされ、必要なすべてのサービスが起動します。

```bash
docker-compose up --build
```
*このコマンドの動作:*
-   *`--build`: Dockerにアプリケーションイメージを再ビルドさせ、最新のコード変更が確実に含まれるようにします。*
-   *`up`: `docker-compose.yaml` ファイルで定義されたすべてのサービス（フロントエンド、バックエンド、データベース）を起動します。*

### 3. アプリケーションにアクセス

コマンドが完了し、サービスが実行されたら、Webブラウザを開いて以下のURLにアクセスしてください。

**http://localhost:8080**

これで、アプリケーションのログイン画面が表示されるはずです。

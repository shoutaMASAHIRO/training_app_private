# Fitness App

リアルタイムでワークアウトスケジュールを管理し、ユーザー認証を提供するクロスプラットフォームのフィットネスアプリケーションです。

---

## プロジェクト概要

このプロジェクトは、ユーザーが日々のワークアウトを **追跡・スケジュール・管理** できるように設計されたモバイルアプリケーションです。ユーザー認証機能を備え、予定されたワークアウトを **カレンダー形式**で表示したり、事前に定義されたトレーニングメニューを選択して **詳細を確認**できます。

---

## アーキテクチャ概要

このプロジェクトは主に **クライアントアプリケーション（Flutter）** で構成されています。

### フロントエンド（`/`）

Flutterで構築されたクロスプラットフォームアプリケーションです。バックエンドAPI（想定）と通信し、ユーザー操作などのUI/UXを提供します。

### バックエンドAPI（想定）

現在、このアプリケーションは **クライアントサイドのみ** の実装ですが、以下の機能のために互換性のあるバックエンドAPIとの連携を想定しています。

- データ永続化
- ユーザー認証
- スケジュール管理

---

## 主な機能

- **ユーザー認証**：ログイン / サインアップ
- **ダッシュボード**：スケジュールされたワークアウトをカレンダーで表示、当日の概要を表示
- **ワークアウトスケジュール管理**：追加 / 完了 / 削除
- **ワークアウトメニュー選択**：定義済みメニュー（例: `Smolov Jr.` / `10x10`）から選択し詳細画面へ遷移
- **プロフィール**：ユーザープロファイル管理（未実装）

---

## 技術スタック

### フロントエンド（Flutter）

- **Flutter / Dart**：単一コードベースで iOS / Android / Web を開発するためのUIツールキット & 言語
- **provider**：状態管理
- **http**：REST API通信
- **intl**：日付・時刻・数値などのフォーマット（国際化/地域化）
- **collection**：コレクション操作ユーティリティ（例：`firstWhereOrNull`）
- **table_calendar**：カレンダーUI
- **shared_preferences**：軽量なローカル永続化（設定・トークン等を想定）

### バックエンド（想定）

- **Node.js / Express.js**：認証・スケジュール管理などのAPI
- **PostgreSQL**：データベース（想定）

## セットアップと起動

### 前提条件

- **Flutter SDK** がインストール済みであること

### 1. バックエンドAPIの起動（開発時のみ）

このアプリはバックエンドAPIと通信することを想定しています。開発中は、互換性のあるAPIサーバーが別途稼働している必要があります。

例：

- PCローカル：`http://localhost:3000`
- Androidエミュレータ：`http://10.0.2.2:3000`

### 2. フロントエンド（Flutter）の起動

1. **ディレクトリ移動**
   ```bash
   cd C:\src\training\fitness_app
   ```

2. **依存関係の取得**
   ```bash
   flutter pub get
   ```

3. **クリーンアップ（推奨）**
   ```bash
   flutter clean
   flutter pub get
   ```
   ※ 以前のビルドキャッシュによる問題を避けるため、`clean` + `pub get` を推奨します。

4. **起動**
   ```bash
   flutter run
   ```
   ※ 接続するデバイス（実機 / エミュレータ）を選択した上で実行してください。

## Android用ビルド・インストール手順

### 1. PCでのビルド手順

1. **プロジェクトルートへ移動**
   ```bash
   cd C:\src\training\fitness_app
   ```

2. **ビルドキャッシュをクリアし、最新パッケージを取得**
   ```bash
   flutter clean
   flutter pub get
   ```

3. **リリース用APKをビルド**
   ```bash
   flutter build apk --release
   ```

- **生成されるファイルのパス**
  - `fitness_app/build/app/outputs/flutter-apk/app-release.apk`

- **注意（サイズが大きい場合）**
  - APKが **100MBを超える** 場合、GitHubへ通常pushできないため **Git LFS** が必要になることがあります。
  - サイズを小さくしたい場合は、以下を推奨します：
    ```bash
    flutter build apk --release --split-per-abi
    ```

### 2. デバイスへのインストール手順

1. PC上の `app-release.apk` を、USB接続 / Googleドライブ等で端末に転送（例：Downloadフォルダ）
2. 端末で **Files by Google** を開く（推奨）
3. **「アプリ」 → 「アプリのインストール ファイル（APK）」** を開く（または **「ダウンロード」**）
4. `app-release.apk` をタップ
5. 「不明なアプリのインストール」警告が出た場合：
   - **「設定」** を押し、該当アプリ（Files等）の許可を **ON**
6. 戻って **「インストール」** をタップ
7. 完了後、ホーム画面にアプリアイコンが追加され、通常のアプリとして起動可能
